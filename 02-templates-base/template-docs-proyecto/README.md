# Plantilla Clonable de Documentación de Proyecto 📝

> **Kit de Inicio Rápido para Nuevos Proyectos en ARTDECON**  
> Copia el contenido de esta carpeta dentro del directorio `/docs` de tu nuevo desarrollo.

---

## 🚀 Instrucciones de Uso

1. Crea una carpeta llamada `docs/` en la raíz de tu proyecto.
2. Copia estos 5 archivos de plantilla renombrándolos (removiendo el sufijo `.template.md` a `.md`):
   * `application-map.template.md` ➡️ `docs/application-map.md`
   * `database-dependency-matrix.template.md` ➡️ `docs/database-dependency-matrix.md`
   * `backend-operation-catalog.template.md` ➡️ `docs/backend-operation-catalog.md`
   * `parity-matrix.template.md` ➡️ `docs/parity-matrix.md`
   * `execution-report.template.md` ➡️ `docs/execution-report.md`
3. Llena cada sección con la información específica de tu herramienta.
4. Consulta la [Guía de Construcción de Herramientas](../../00-guia-construccion-herramientas/README.md) ante cualquier duda de formato.
