## 📌 Estado de Integración de Cada Proyecto

Para que un proyecto del catálogo pase a estado **🟢 PRODUCTIVO / HOMOLOGADO POR XTEIN**, debe:
1. Tener su carpeta dentro de este catálogo.
2. Contar con sus **5 documentos canónicos** dentro de su subcarpeta `/docs`.
3. Cumplir con el [Checklist de Aprobación XTEIN](../00-guia-construccion-herramientas/05-checklist-aprobacion.md).
